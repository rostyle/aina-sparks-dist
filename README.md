# AiNA SPARKS

株式会社AiNA BRAIN が提供するデスクトップアプリ **AiNA SPARKS** の配布用リポジトリです。
インストーラのみを置いています（ソースコードは含みません）。

最新版は [Releases](../../releases) から取得してください。

- **Windows**: `AiNA SPARKS Setup x.y.z.exe`
- **Mac（Apple Silicon / M1以降）**: `AiNA SPARKS-x.y.z-arm64.dmg`
- **Mac（Intel）**: `AiNA SPARKS-x.y.z-x64.dmg`

ご利用にはAiNAの会員アカウントが必要です。
